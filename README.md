# FitHive Gym Website

## Project Overview

FitHive is a responsive gym website built to provide users with an easy and engaging way to explore fitness services. It allows visitors to view membership plans, search for trainers and get in touch through a contact form. The design focuses on simplicity, smooth interactions and a clean user interface to create a comfortable browsing experience.

## Tech Stack

* Frontend: React.js
* Styling: CSS3 (including dark and light mode support)
* Animations: Framer Motion
* Routing: React Router DOM
* Form Integration: EmailJS API

## Setup Instructions

Follow these steps to run the project locally:

### 1. Clone the repository


git clone https://github.com/sanju20021001/gym-website.git


### 2. Navigate into the project folder

cd gym-website

### 3. Install dependencies

npm install

### 4. Start the development server

npm run dev

### 5. Open in browser

Visit the following URL in your browser

http://localhost:5173
